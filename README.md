Aplicação web desenvolvida em PHP para cadastro e gerenciamento de clientes, com persistência de dados em MySQL.

Funcionalidades

Cadastro de clientes

Listagem de registros

Edição de dados

Exclusão de clientes com confirmação

Pesquisa por nome ou e-mail

Validação de campos obrigatórios e formato do e-mail

Mensagens de sucesso e erro

Tecnologias utilizadas

PHP

MySQL

PDO

HTML5

CSS3

Git

Arquitetura

O projeto utiliza uma organização inspirada no padrão MVC (Model-View-Controller), separando as responsabilidades:

Model: operações de acesso e manipulação dos dados.

Controller: coordenação das ações da aplicação.

View: apresentação da interface ao usuário.

Banco de dados

Banco de dados: sistema_clientes

Tabela principal: clientes

Campos: id, nome, email, telefone e criado_em.

Como executar localmente

Instale o Laragon com PHP e MySQL/MariaDB.

Coloque o projeto na pasta www do Laragon.

Crie o banco de dados sistema_clientes e a tabela clientes.

Configure a conexão em conexao.php.

Inicie o Apache e o MySQL.

Acesse http://localhost/sistema-clientes/public/.

Objetivo

Projeto de portfólio para demonstrar conhecimentos em desenvolvimento web com PHP, organização de código, operações CRUD, consultas SQL preparadas e integração com banco de dados.
